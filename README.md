# Manual do Vendedor

Projeto pronto para subir no GitHub e hospedar pela Vercel.

## Vercel

- Install command: `pnpm install --frozen-lockfile`
- Build command: `pnpm run build`
- O build usa Nitro com preset `vercel` e gera a saida em `.vercel/output`.

## Local

```bash
pnpm install
pnpm run dev
```
